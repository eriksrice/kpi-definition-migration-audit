# Reproducibility

## Requirements

- Python `3.12`
- `uv` for locked environment synchronization
- POSIX shell for repository scripts

## Environment setup

From the repository root:

```sh
./scripts/bootstrap_environment
```

The script runs `uv sync --frozen --extra dev --python 3.12` against `uv.lock`. The first setup may download locked distributions. Runtime proof and demo execution do not access the network.

To require an already populated uv cache:

```sh
TRIAL_OFFLINE=1 ./scripts/bootstrap_environment
```

## Demonstration

```sh
./scripts/run_demo
```

The command generates evidence and schemas in a temporary directory, compares every generated byte with the checked-in canonical trees, prints the machine-derived demo only after equality passes, and removes the temporary output.

## Complete verification

```sh
./scripts/test_golden
```

This runs all tests plus Ruff lint and formatting checks. To explicitly rewrite and compare the canonical output:

```sh
./scripts/run_golden
git diff --exit-code -- artifacts/golden schemas
```

`run_golden` is deterministic for the checked-in fixtures. Use it only in a clean worktree when intentionally verifying canonical regeneration.

## Expected evidence surface

- Python `3.12.x`
- 105 passing tests
- 15 files under `artifacts/golden/`
- 26 files under `schemas/`
- G1–G4 all `PASS`
- no runtime network or LLM dependency
